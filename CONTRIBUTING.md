# Как дополнить справочник

Справочник открыт для правок. Он растёт из поисков конкретных людей, поэтому в нём густо там,
где искали, и пусто там, где не искали. Каждое новое дело избавляет следующего исследователя от
дня работы. Особенно нужны:

- **новые дела** — писцовые, переписные и ревизские книги XVII–XVIII веков любого уезда;
- **найденные наборы** — если дело уже кто-то набрал, а у нас оно отмечено как «только образы»;
- **исправления** — год, шифр, число листов, состояние оцифровки, неработающая ссылка;
- **замечания к машинным чтениям** — лист, где чтение явно не про то дело, или дело, которое
  стоит прочитать.

## Два пути

**Проще всего — [issue](https://github.com/dtretyakov/perepisi-catalog/issues/new).** Напишите,
что знаете, в свободной форме; всё остальное мы сделаем сами. Для нового дела достаточно:

- архив, фонд, опись, дело;
- годы и заголовок, как в описи или на карточке дела;
- где лежат образы, если лежат: ссылка на карточку дела в каталоге архива;
- если есть набор — ссылка на него и чей он;
- откуда сведения: печатная опись, карточка ГИС УИАД, сам образ.

**Для тех, кто работает с git, — pull request** с правкой `tools/cases.json` (см. ниже).

## Как устроена запись дела

Всё содержимое справочника — один файл, [`tools/cases.json`](tools/cases.json). Карточки в
`cases/`, таблица [`CATALOG.md`](CATALOG.md) и [`data/cases.json`](data/cases.json)
**собираются из него скриптом** — их руками не правят.

```json
{
 "id": "rgada-350-2-1620",
 "arch": "РГАДА", "f": "350", "o": "2", "d": "1620",
 "years": "1748",
 "title": "Книга переписная однодворцев и дворовых г. Кромы…",
 "scans": "ГИС УИАД",
 "state": "только образы",
 "set": "", "set_url": "",
 "case_url": "https://online.archives.ru/guide/…/10000004078014/",
 "leaves": 866, "leaves_src": "опись",
 "images": 871, "shot": "разворотами",
 "note": "Что внутри и на чём можно споткнуться."
}
```

| поле | что писать |
|---|---|
| `id` | `<архив>-<фонд>-<опись>-<дело>` латиницей и строчными: `rgada-…`, `gapk-…`, `gaso-…` |
| `arch`, `f`, `o`, `d` | архив и шифр ровно как в описи |
| `years` | крайние даты по описи; если исправлены по самому делу — сказать об этом в `note` |
| `title` | заголовок дела из описи или с карточки архива, без сокращений от себя |
| `scans` | где образы: `ГИС УИАД`, `каталог архива`, `микрофильм`; пусто, если нигде |
| `state` | одно из пяти: `набрана`, `частично набрана`, `только машинное чтение`, `только образы`, `только опись` |
| `set`, `set_url` | название набора и ссылка на него — **только ссылка**, текст не копируется |
| `case_url` | карточка дела в каталоге архива; открывается без оплаты |
| `leaves`, `leaves_src` | число листов и откуда оно: `опись` или `сосчитано по образам` |
| `images`, `shot` | число образов и как снято: `разворотами` или `постранично` |
| `leaf_range` | нумерация листов, если известна: `20–265` |
| `note` | состав дела, где что лежит, ловушки. Без родословных и без живых людей |

Поля машинного чтения (`htr`, `htr_model`, `htr_conf`, `tabular`) заполняются только вместе
с самим чтением — их оставьте пустыми.

После правки:

```bash
python3 tools/build.py
```

Скрипт пересоберёт карточки, таблицу и `data/cases.json` и предупредит, если число листов не
сходится с нумерацией. В pull request кладите и `tools/cases.json`, и то, что пересобралось.

## Прежде чем отметить состояние

Состояние — главное, что справочник сообщает, и ошибка в нём стоит читателю дня работы.
Поэтому его ставят по проверенному, а не по впечатлению:

- **«оцифровано»** проверяется не по карточке, а по [таблице оцифровки ГИС УИАД](https://metrics.tilda.ws/gisuiad) или по
  самому просмотрщику: на карточке пометки бывают, а образов нет;
- **«набрана»** — только если набор **дословный**. Сверьте одну-две строки набора с образом.
  Выписка, пересказ, текст без номеров душ или без формул — это «частично набрана», даже если
  имена все на месте;
- **год** берите из описи, а если он спорный — из самого дела, и напишите, откуда.

## Чего не присылать

- **Образов.** Соглашение ГИС УИАД (п. 6.3) запрещает их выкладывать; см. [rights.md](rights.md).
- **Чужих наборов.** Только ссылки на них; текст принадлежит тому, кто его набрал.
- **Частных исследований**: родословных, сведений о живых людях.

## Машинные чтения

Чтения делаются опубликованными моделями (раздел «Про машинное чтение» в [README](README.md)) по
образам, к которым у нас есть доступ. Если хотите, чтобы дело прочитали, — откройте issue с его
шифром; если чтение уже есть и явно ошибается — укажите лист.
