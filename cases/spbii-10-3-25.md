# СПб ИИ РАН ф.10 оп.3 д.25

18 волостей, 544 двора, текст полный. Фамилию носят 16 дворохозяев из 544 — отсутствие фамилии в этой книге почти ничего не доказывает. На странице текст напечатан ДВАЖДЫ: дипломатически и нормализованно, это удваивает всякий подсчёт по регулярному выражению. Есть итоги по волостям: Кеврольский стан 251 двор / 694 человека, Выйская с Керескими 106 / 354, Перемская 85 / 187, Сурская с Сулецкими 80 / 287, Лавельская 34 / 138, Марьина гора 16 / 71. Деревни носят двойные и тройные имена через «тож» — этим набором читается название деревни, не дающееся в книге 1623 года.
