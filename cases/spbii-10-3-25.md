# СПб ИИ РАН ф.10 оп.3 д.25

| | |
|---|---|

Набор Е. Немытовой. Книга сокращённая — 68 листов на весь уезд, зато с итогами по волостям и с полными названиями деревень. Кеврольский стан 251 двор / 694 человека, Выйская с Керескими 106 / 354, Перемская 85 / 187, Сурская с Сулецкими 80 / 287, Лавельская 34 / 138, Марьина гора 16 / 71. Деревни здесь носят двойные и тройные имена через «тож» — этим набором читается название, не дающееся в книге 1623 года.
