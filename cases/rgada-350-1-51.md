# РГАДА ф.350 оп.1 д.51

**Книга перечневая итогов переписи 1678 года: Важский, Двинской, Кеврольский, Мезенский, Кольский уезды**

| | |
|---|---|
| Годы | 1678 |
| Состояние | ⚪ только образы |
| Образы | ГИС УИАД, оцифровано |
| Объём | листов 158 (по описи) · образов 167 |
| Опись | [поиск РГАДА](http://rgada.info/poisk/) · [Великие описи](https://inv.velikie.org/archive/rgada/350/) |

, 167 образов. Кеврольский уезд — лл.134–143. Опись зовёт дело «Книга перечневая итогов переписи 1678 г.»; год в нашей таблице прежде стоял 1720 — это дата составления списка, а не переписи, и для поиска она сбивает.

ПРОЧИТАНО 21 сентября 2026 года. ЛАВЕЛЬСКАЯ ВОЛОСТЬ, л.141об: «Приемных — 3 двора, людей в них — 7 человек. Крестьянских — 29 дворов, людей в них — 61 человек. Да тех же хоромов — 2 двора, тяглых, дворе вины не написано. Итого 32 двора, 98 человек». ВЕРКОЛЬСКАЯ, л.141: приемных 3 двора (9 человек), тяглых 78 (27 человек), итого 11 дворов, 15 человек.

Зачем это дело: подворная книга той же переписи 1678 года — ф.1209 оп.1 д.15055 — существует только микрофильмом, и её нет ни в одном цифровом собрании. Эти итоги заменяют её числами; имён в них нет.

ЛОВУШКИ: имена файлов в mediaList ПУСТЫ, образы приходится нумеровать по порядку; соответствие устанавливается по номерам на правых страницах — ОБРАЗ = ЛИСТ + 4. Волости Кеврольского уезда идут так: Кеврольский стан, Пиринемская, Чакольская, Перемская, Веркольская (л.141), Лавельская (л.141об), Сура и Нюхча (л.142), Малопенежская.
