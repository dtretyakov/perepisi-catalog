# ГАПК ф.111 оп.1 д.2626

**Ревизская сказка 1811 года, Пермская губерния, Верхотурский уезд, Топорковская волость — о состоящих государственных крестьянах**

| | |
|---|---|
| Годы | 1811 |
| Состояние | машинное чтение |
| Образы | archives.permkrai.ru, оцифровано (unit 76338) |
| Машинное чтение | [текст](../text/gapk-111-1-2626.md), 8.4 знака на строку, модель «Kansallisarkisto/cyrillic-htr-model» |

55 листов, 59 образов — и это РАЗВОРОТЫ: на каждом снимке две исписанные страницы, номер листа стоит только на правой. Кто нарежет правые половины, потеряет половину книги и половину деревень; проверено на себе.

На обложке: «Ревизская сказка имения графа Шувалова Топорковской волости» — то есть это те самые приписные к заводам крестьяне, а не отдельная «заводская» книга, которой за 1811 год в фонде нет вовсе. Деревни идут так: Кокшарова, Серкина, Тычкина, БОРОВСКАЯ (л.5об-6, «итого 34»), Тунгусы, Казарина, Нотрина, Минеева, Луговая, Лачева Большая, Кряжская, Новосёлова, Подосёлова, Павланова, Березникова, Синявина, Цыплова, Бабина, Запорудина, Верхотуркина, Суханова, Бабалова, Берсенёва, Толмачёва, Комлева, Ларионова, Ерехова, Массалова, Савина, Зубкова, Тишкина, Фомина Большая, Ретнева, Топкова, Черновская, Хмелёва, Кашкинский починок, Баланина, Резанский починок.

В деревне Минеевой сидят ПИНЕЖАНИНЫ — фамилия, которая называет, откуда пришли: с Пинеги.

> Машинное чтение — не транскрипция. На этой руке модель ошибается в каждом третьем знаке и охотно сочиняет правдоподобное. Годится, чтобы найти страницу по корню слова; не годится, чтобы цитировать.
