# ГАПК ф.111 оп.1 д.2626

**Ревизская сказка 1811 года, Пермская губерния, Верхотурский уезд, Топорковская волость — о состоящих государственных крестьянах**

| | |
|---|---|
| Годы | 1811 |
| Состояние | машинное чтение |
| Образы | archives.permkrai.ru, оцифровано (unit 76338) |

55 листов, 59 образов. В 1800 году деревня Боровская (она же Мянишева) числилась «Топорковской волости подзаводскими крестьянами», так что эта книга — первое место, где её искать за 1811 год. Читается тем же распознавателем, что и д.2633.
