# ГАПК ф.111 оп.1 д.2966

**Ревизские сказки V ревизии, Верхотурский уезд, Топорковская волость — приписные к Гороблагодатским заводам**

| | |
|---|---|
| Годы | 1795 |
| Состояние | ⚪ только образы |
| Образы | archives.permkrai.ru (вход по учётной записи) |

Деревня Боровская начинается на ПРАВОЙ странице образа 17 и идёт по образ 21; двор Григорья Кирилова — образ 20, итог деревни — образ 21. Ловушка: внизу левой страницы образа 17 стоит итог ПРЕДЫДУЩЕЙ деревни (47·16·55·63·36·59), его легко принять за свой. Шесть колонок: по 1782 году, выбыло, ныне налицо — отдельно мужские и женские. ВАЖНО: эта ревизия считает только приписных к заводам, то есть часть деревни; сравнивать её с подворными переписями нельзя.
