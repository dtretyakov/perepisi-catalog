# Переписи и ревизии XVII–XVIII веков: что уже набрано, а что нет

Справочник для тех, кто ищет предков в писцовых, переписных и ревизских книгах
XVII–XVIII веков. Сейчас в нём уезды Урала и Прикамья, Русского Севера и Пинеги,
Вятки, Орловской и Курской земель, Западной Сибири, а по Верхотурскому уезду — и ревизии
XIX века; список растёт по мере того, как дела читаются.

Справочник отвечает на один вопрос, выяснение которого обычно занимает день работы, а нередко требует и расходов:

> **Это дело уже кто-то набрал — или придётся читать образы самому?**

<a id="gde-iskat"></a>

## Где искать

Справочник разложен так, как ищут предков: сначала место, потом время. На странице
области дела собраны по уездам, а внутри уезда идут по годам: видно, какая перепись
шла раньше и какая позже, кто в ней записан и можно ли её прочесть.

Состояния:

| | |
|---|---|
| 🟢 набрана | текст набран человеком и доступен для полнотекстового поиска; ссылка в карточке дела |
| 🟡 набрана частично | набрана часть — обычно выписки по отдельным деревням |
| 🔵 машинное чтение | набора нет; доступно машинное распознавание, пригодное для поиска, но не для цитирования |
| ⚪ только образы | ни набора, ни распознавания: требуется доступ к образам и чтение с листа |
| ⚫ только опись | дело не просматривалось; сведения взяты из описи |

У дел с машинным чтением рядом стоит знак того, чего это чтение стоит. В таблице
только знак; оценка и числа, по которым она выставлена, — в карточке дела.

| | |
|---|---|
| 🟩 | от 75 % — чтение рабочее: по нему ищут и находят |
| 🟨 | 45–75 % — чтение с потерями: искать можно, полагаться нельзя |
| 🟥 | ниже 45 % — шум |

Знак складывается из двух мер, и берётся **худшая**.

**Что модель показала на книгах того же времени.** Это доля верных знаков на строках,
размеченных вручную, — единственная мера, которая говорит, сколько в чтении правды.
На 1680 год это 93 %, на 1718–1720-е — 90 % на книгах, которых модель не видела,
на 1740-е — 61 %, от 49 до 70 % в зависимости от писца. Для 1620–1650-х мерка есть
только на книге, которую модель видела при обучении, и чужие руки того времени поэтому
выше 🟨 не получают. Где размечено само дело, берётся его мерка.

**Берёт ли модель эту руку вообще** — плотность знаков на строку и уверенность модели.
На своей руке плотность под тридцать, ниже двенадцати — чистый шум; на табличном деле,
где имя, отчество и возраст стоят в разных клетках, она считается от десяти. Уверенность
поодиночке обманывает: на скорописи 1632 года чужая модель выдавала вымысел при 0,99.
Обе приводятся к доле от достижимого и сводятся средним геометрическим, так что провал
в одной не вытягивается другой.

Первая мера ставит потолок, вторая ловит книгу, которую модель не берёт вовсе. Густой
текст 1748 года при плотности под тридцать остаётся 🟨: плотность говорит, что модель
пишет много, но не говорит, что верно.

## Машиночитаемые данные

То же содержимое, что в карточках и чтениях, лежит в JSON — для скриптов, поиска по всем делам
сразу и сравнения чтений разными версиями модели. Markdown собирается из тех же данных, так что
расхождений между ними нет.

- **[data/cases.json](data/cases.json)** — все дела каталога: шифр, годы, состояние, объём, ссылки
  на ГИС УИАД и на набор; нынешняя область, уезд, вид книги, перепись, сословия и места с листами;
  а для распознанных — модель (со ссылкой на её версию), плотность, уверенность, мерка точности
  и оценка.
- **data/readings/&lt;дело&gt;.json** — машинное чтение дела: по записи на кусок (`label` — «л. 23об»
  или «образ 5a», `kind` — `leaf` или `image`, `number`, `side`) со строками распознавания как есть.

У обоих файлов есть `schema_version`; поля в пределах версии только добавляются. Прямые адреса на
сайте: `https://dtretyakov.github.io/perepisi-catalog/data/cases.json` и
`…/data/readings/<дело>.json`. Координат строк на образе здесь нет и не будет: без образа они
бесполезны, а образы не публикуются.

## Чего здесь нет и не будет

**Образов.** Пользовательское соглашение ГИС УИАД, п. 6.3, прямо запрещает загружать
образы из просмотрщика, и это единственный запрет, который здесь действительно
действует. Подробно — в [rights.md](rights.md).

**Чужих наборов.** Тексты Ю. В. Коновалова, census1710.narod.ru, zz-project.ru и
«Родной Вятки» — многолетний труд конкретных людей. Здесь только ссылки на них.
За текстом следует обращаться к авторам.

**Частных исследований.** Ни родословных, ни живых людей.

А вот сведения, вычитанные из архивных дел, распространять **можно**: это прямая
норма ст. 26 п. 1 закона об архивном деле. На том же основании Ю. В. Коновалов
публикует наборы переписных книг с 1990-х годов. Разбор — в [rights.md](rights.md).

## Про машинное чтение

Там, где набора нет, публикуется машинное распознавание — результат работы модели,
обученной на русской скорописи XVII века.

Модели, которыми сделаны чтения, опубликованы, и в карточке каждого дела указана та, что его читала:

- **скоропись-12** — модель для kraken, приказная скоропись 1620–1720-х с выходом в 1740–60-е.
  Концептуальный DOI [10.5281/zenodo.22905349](https://doi.org/10.5281/zenodo.22905349) ведёт
  на новейшую версию. Чтения этого каталога сделаны версиями 2
  ([10.5281/zenodo.22905381](https://doi.org/10.5281/zenodo.22905381)), 3
  ([10.5281/zenodo.22912945](https://doi.org/10.5281/zenodo.22912945)) и 8
  ([10.5281/zenodo.22933888](https://doi.org/10.5281/zenodo.22933888)).
- **Kansallisarkisto/cyrillic-htr-model** — модель Национального архива Финляндии для
  гражданского письма XIX века ([Hugging Face](https://huggingface.co/Kansallisarkisto/cyrillic-htr-model));
  ею прочитаны ревизские сказки 1811 года.

**Это не транскрипция.** На хорошей руке модель даёт около тридцати знаков на строку
и узнаваемые имена; на трудной — тринадцать, и тогда в тексте нет ничего, кроме шума.
Плотность указана в каждой карточке.

**На табличных делах плотность не показательна.** Ревизская сказка расставляет имя, отчество, фамилию
и возраст по разным клеткам, и распознаватель честно выдаёт десятки коротких строк.
Книга 1811 года вышла на 9,4 знака — по шкале выше это «шум», — а читается она почти
без ошибок: «потанъ Гурьгов Сенъбулаев» при уверенности 0,97 есть Потап Гурьев сын
Булаев, и так вся книга. **На табличном деле показательна средняя уверенность; плотность знаков
имеет смысл только в сплошном тексте.**

Область применения: поиск страницы по корню слова с учётом того, что
модель пишет «Тронка» вместо «Тренка» и «пинежени» вместо «пенежан». Искать следует по корню
с заменой гласных, просматривая все совпадения, а не первое.

Для цитирования распознавание непригодно. Зафиксирован случай, когда модель выдала
связную дворовую запись с именем и возрастом на листе, где в оригинале стоял иной текст.

## Почему это появилось

Справочник составлен в ходе частного генеалогического розыска: при поиске крестьянского
двора на реке Тагиле потребовалось обратиться к четырём архивам, трём волонтёрским
проектам и пяти томам «Пермской летописи». Значительная часть времени ушла на выяснение
сведений, которые здесь сведены в одну строку таблицы.

## Помочь

Если вам известен набор, отсутствующий в справочнике, или сведения об оцифровке дела,
либо обнаружена ошибка в шифре, — откройте issue или pull request. Карточки собираются скриптом из `tools/cases.json`:

```bash
python3 tools/build.py
```

Машинные чтения собираются отдельно, из рабочего каталога исследования:

```bash
python3 tools/text.py
```
