# Переписи Урала и Русского Севера: что уже набрано, а что нет

Справочник для тех, кто ищет предков в писцовых, переписных и ревизских книгах
XVII–XVIII веков по Верхотурскому, Кеврольскому, Соликамскому и Чердынскому уездам.

Он отвечает на один вопрос, который стоит дня работы и часто — денег:

> **Это дело уже кто-то набрал — или придётся читать образы самому?**

## Как пользоваться

- **[CATALOG.md](CATALOG.md)** — таблица всех дел. Колонка «Состояние» говорит главное.
- **[sources.md](sources.md)** — где лежат наборы и образы, как туда попасть, сколько стоит
  и на чём люди спотыкаются.
- **cases/** — карточка на каждое дело: шифр, годы, ссылки, оговорки.

Состояния:

| | |
|---|---|
| 🟢 набрана | текст набран человеком, ищется поиском. Идите по ссылке |
| 🟡 набрана частично | набрана часть — обычно выписки по отдельным деревням |
| 🔵 машинное чтение | набора нет; у нас есть распознавание, годное для поиска, но не для цитирования |
| ⚪ только образы | ни набора, ни чтения. Платить и читать глазами |
| ⚫ только опись | само дело не смотрели; известно только из описи |

## Чего здесь нет и не будет

**Образов.** Архивы отдают их по своим правилам, часть — за деньги. Выкладывать их
здесь было бы и нечестно, и незаконно.

**Чужих наборов.** Тексты Ю. В. Коновалова, census1710.narod.ru, zz-project.ru и
«Родной Вятки» — многолетний труд конкретных людей. Здесь только ссылки на них.
Если вам нужен текст — идите к авторам и поблагодарите их.

**Частных исследований.** Ни родословных, ни живых людей.

## Про машинное чтение

Там, где набора нет, мы иногда кладём распознавание — результат работы модели,
обученной на русской скорописи XVII века.

**Это не транскрипция.** На хорошей руке модель даёт около тридцати знаков на строку
и узнаваемые имена; на трудной — тринадцать, и тогда в тексте нет ничего, кроме шума.
Плотность указана в каждой карточке, потому что она и есть мера доверия.

Чем таким чтением можно пользоваться: искать страницу по корню слова, зная, что
модель пишет «Тронка» вместо «Тренка» и «пинежени» вместо «пенежан». Ищите по корню
с заменой гласных и печатайте все попадания, а не первое.

Чем нельзя: цитировать. Проверено на своей шкуре — модель выдала складную дворовую
запись с именем и возрастом там, где на образе стоял совсем другой текст.

## Почему это появилось

Собрано попутно, во время одного частного розыска: пока искали крестьянский двор
на реке Тагиле, пришлось перебрать четыре архива, три волонтёрских проекта и пять
томов «Пермской летописи». Половина времени ушла на выяснение того, что здесь
написано в одной строке таблицы.

Если сэкономит кому-то этот день — значит, не зря.

## Помочь

Нашли набор, которого здесь нет; знаете, что дело оцифровано; поймали ошибку в шифре —
откройте issue или pull request. Карточки собираются скриптом из `tools/cases.json`:

```bash
python3 tools/build.py
```
