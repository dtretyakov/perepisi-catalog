# РГАДА ф.214 оп.1 д.106 — машинное чтение

**Книга десятинной пашни Верхотурского уезда**

Годы: 1636/37. Листов прочитано: 345, строк: 3822. Модель [скоропись-12 v8](https://doi.org/10.5281/zenodo.22933888), 27.5 знака на строку.

> **Это машинное распознавание, а не транскрипция.** Модель ошибается в знаках, смешивает близкие буквы и способна дать связный, но неверный текст. Материал пригоден для **поиска листа** по корню слова; для цитирования непригоден. Найденное место следует сверять с образом.

Порядок поиска: по корню с заменой гласных — модель передаёт «Тренка» как «Тронка», «пенежан» как «пинежени». Просматривать следует все совпадения, а не первое.

Шифр для ссылки: **РГАДА ф.214 оп.1 д.106**. В заголовке куска стоит то, чем дело снято: «л. N» — лист, «образ Na/Nb» — левая и правая страницы одного разворота. Перевести образ в лист может только оглавление дела, и здесь этого не делается.
